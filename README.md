# 致城顾问项目 · 交付追踪台

> 智能项目交付追踪与日程规划工作台  
> 访问地址：<https://sxie738-bot.github.io/zhicheng-delivery-tracker/>

---

## ✅ 功能说明

| 功能 | 说明 |
|------|------|
| 📋 交付追踪 | 31项交付物打卡，支持备注 |
| 📁 文件上传 | 每个交付项可上传对应文档，存于浏览器本地 |
| 📊 进度看板 | 实时完成率 + KPI监控 |
| ⚠️ 风险监控 | 四色预警，自动提醒临近节点 |
| 🗓️ 智能规划 | 基于合同里程碑，自动生成今日/明日/本周行动建议 |
| 📤 数据同步 | 导出JSON → 微信发同事 → 同事导入即可同步 |

---

## 🚀 使用方式（两种）

### 方式一：网页版（推荐）
直接浏览器打开：<https://sxie738-bot.github.io/zhicheng-delivery-tracker/>

> ⚠️ 数据存在浏览器 localStorage，不同设备/浏览器之间**不共享**数据  
> 如需跨设备同步，请使用「方式二」

### 方式二：桌面离线版
1. 下载本仓库的 `index.html` 保存到桌面
2. 双击打开，完全离线可用
3. 数据通过「导出/导入JSON」在团队成员间同步

---

## 🔄 团队数据同步步骤

```
[你] 点击「📤 导出数据」→ 下载 zhicheng-data-YYYYMMDD-HHMM.json
     ↓
     通过微信/邮件发给团队同事
     ↓
[同事] 点击「📥 导入数据」→ 选择你发的 .json 文件
     ↓
     追踪台自动加载你的最新进度 ✅
```
